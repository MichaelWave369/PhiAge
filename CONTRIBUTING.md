# Contributing to ΦAge

Contributions are welcome in the spirit of open scientific collaboration.

## For hypotheses
Provide a stable ID, relevant aging hallmark, a narrow falsifiable claim, a preregistered rejection criterion, competing explanations, and an honest endpoint hierarchy. Link primary evidence, record species, study design, conflicts, source independence, and uncertainty.

## For code
Use dependency-light implementations, deterministic tests, documented data licenses, immutable source hashes, and accessible user interfaces. Add a test for each changed behavior. Declare when an output is simulated or synthetic. Never write "proved" for a single observational signal.

## Exclusions
Do not upload private patient information, real identifiable genomic data, unauthorized datasets, dangerous self-experimentation instructions, or unsupported longevity treatment claims. Clinical and laboratory trials require qualified scientific and ethical oversight.

## Multi-agent research roles (planned)
Evidence curator, mechanistic modeler, causal critic, replication engineer, safety reviewer, and validation auditor. Each role logs assumptions and contradictory findings. **Automated scientific discovery is not yet implemented.**
